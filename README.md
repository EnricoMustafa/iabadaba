# iabadaba

Um jogo minimalista de memória de cores.

## Como jogar

1. **Memorize** a cor exibida na tela — você tem 5 segundos
2. **Escolha** entre 6 tons qual era a cor original — você tem 5 segundos
3. **Veja** sua pontuação com base em quão próxima foi sua escolha
4. Repita por **5 rodadas** e veja seu total

A pontuação vai de 0 a 100 por rodada — acertar a cor exata vale 100 pontos.

## Stack

- [React 18](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- Web Audio API (sons gerados em tempo real, sem arquivos externos)

## Rodando localmente

```bash
git clone https://github.com/EnricoMustafa/iabadaba.git
cd iabadaba
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no browser.

## Build

```bash
npm run build
```

Os arquivos gerados ficam em `/dist`.
